# LinkMap — มายแมปจดเรียน จัดผังอัตโนมัติ

เว็บแอปจดโน้ตแบบมายแมปที่ **จัดผังให้เองทุกครั้งที่พิมพ์หัวข้อใหม่** เหมาะกับการจดตามอาจารย์สอนเร็ว ๆ
ไม่ต้องเสียเวลาลากจัดเส้นเอง ทำงานในเครื่องทั้งหมด (local-first) ไม่ส่งข้อมูลออกอินเทอร์เน็ต ไม่มีค่าใช้จ่าย
และไม่ใช้ไลบรารีภายนอกเลย (ดู `THIRD_PARTY_NOTICES.md`)

นอกจากมายแมปแล้ว ยังมีเครื่องมือ "วิเคราะห์ความเชื่อมโยง" แบบ link analysis (centrality / ชุมชน / เส้นทางสั้นสุด)
และเลย์เอาต์อีกหลายแบบ สำหรับใครที่อยากใช้ทำผังเครือข่ายทั่วไป — ซ่อนอยู่ในเมนู ไม่รบกวนการจดโน้ต

## เปิดใช้งาน

1. ดับเบิลคลิก **`เปิดLinkMap.cmd`** (ต้องมี Python 3 หรือ Node.js ในเครื่อง — มีตัวใดตัวหนึ่งก็พอ)
2. เบราว์เซอร์จะเปิด `http://127.0.0.1:8781/` ให้เอง หน้าต่างดำเล็ก ๆ ที่ค้างอยู่คือเซิร์ฟเวอร์ ปิดหน้าต่างนั้นเมื่อเลิกใช้
3. ครั้งแรกจะเห็นตัวอย่าง "สรุปบทเรียน" ให้ลองกดดูได้เลย

ทางเลือกอื่น: `python serve.py` หรือ `node serve.js` ในโฟลเดอร์นี้ (ถ้าพอร์ตชน จะหาพอร์ตว่างถัดไปให้)

> งานจะ **บันทึกอัตโนมัติ** ไว้ในเบราว์เซอร์ (localStorage) ทุกครั้งที่แก้ และควร **บันทึกเป็นไฟล์ JSON** (Ctrl+S) เก็บไว้เองด้วยเป็นระยะ

## วิธีจดโน้ตแบบเร็ว (โหมดจดเรียน)

| ทำอะไร | กด |
|---|---|
| สร้างหัวข้อหลัก (ตอนผังว่าง) | `Enter` หรือดับเบิลคลิกพื้นว่าง |
| จดหัวข้อถัดไป (พี่น้อง) | เลือกหัวข้อ แล้วกด `Enter` |
| จดหัวข้อย่อย (ลูก) | เลือกหัวข้อ แล้วกด `Tab` (หรือ `Shift+Enter`) |
| พิมพ์ต่อเนื่อง | พิมพ์ข้อความ → `Enter` = ต่อพี่น้องทันที → `Tab` = ลงไปลูก → `Enter` บนหัวข้อว่าง = หยุด |
| แก้ข้อความหัวข้อ | ดับเบิลคลิก, `F2`, หรือพิมพ์ตัวอักษรใด ๆ ขณะเลือกหัวข้อนั้น |
| จัดผังมายแมปใหม่ทั้งหมด | `1` หรือ `Ctrl+L` (เมนู จัดผัง › มายแมป) |
| ฟิตให้เห็นทั้งผัง | `F` |

แอปจะจัดผังมายแมปให้อัตโนมัติทุกครั้งที่เพิ่มหัวข้อ (ปิดได้ที่ เมนู จัดผัง › "จัดผังมายแมปอัตโนมัติ")
กิ่งแต่ละสายจากหัวข้อหลักจะได้สีประจำกิ่งต่างกันเอง

## ตกแต่งหัวข้อและธีม

- **ธีมสี** ที่เมนู มุมมอง: คลาสสิก / พาสเทล / สดใส / ขาวดำ / **มืด** (บันทึกไปกับไฟล์ผัง สีกิ่งเปลี่ยนตามธีม)
- **รูปทรงหัวข้อ**: อัตโนมัติ / มุมโค้ง / แคปซูล / สี่เหลี่ยม / ขีดเส้นใต้ — ตั้งทีละหัวข้อหรือ "ทั้งกิ่ง" ในแผงคุณสมบัติ
- **ตัวหนา / ตัวเอียง** `Ctrl+B` / `Ctrl+I`
- **รูปภาพในหัวข้อ**: ปุ่ม "เพิ่มรูป…" ในแผงคุณสมบัติ หรือเลือกหัวข้อแล้ว `Ctrl+V` วางรูปจากคลิปบอร์ด (รูปถูกย่อและเก็บไว้ในไฟล์ผัง)
- **ลากหัวข้อไปแทรกตำแหน่ง**: ลากหัวข้อไปปล่อยใกล้พี่น้องเพื่อเปลี่ยนลำดับ หรือปล่อยใกล้ลูกของกิ่งอื่นเพื่อย้ายไปกิ่งนั้น (ปล่อยทับหัวข้อ = ย้ายไปเป็นลูกของหัวข้อนั้น)

## เมาส์และผืนผ้าใบ

- **ล้อเมาส์** ซูม · **ลากปุ่มกลาง / Space ค้างแล้วลาก / เครื่องมือ "เลื่อน"** แพน
- **ลากหัวข้อ** ย้าย (ลากหลายตัวได้หลังเลือกหลายตัว) · **ลากพื้นว่าง** เลือกเป็นกรอบ · **Shift+คลิก** เลือกเพิ่ม/ลด
- **ลากจากจุดเล็กข้างหัวข้อ** (หรือ Alt+ลาก) ไปปล่อยที่อีกหัวข้อ = สร้างเส้นเชื่อมใหม่ · ดับเบิลคลิกเส้นเพื่อใส่ป้าย
- **คลิกขวา** เมนูลัด (เปลี่ยนประเภท ลบ ซ่อน ขยายเพื่อนบ้าน ฯลฯ)
- **โน้ตติดกาว** (`T`) และ **กรอบจัดกลุ่ม** (`G` หรือลากวาด) — ลากมุมขวาล่างเพื่อปรับขนาด; ย้ายกรอบจะพาโหนดข้างในไปด้วย

## แผงด้านขวา

- **คุณสมบัติ** — แก้ชื่อ ประเภท สี วันเวลา แหล่งที่มา หมายเหตุ และแอตทริบิวต์ key/value ของโหนด/เส้นที่เลือก
- **รายการ** — ตารางโหนด/เส้นทั้งหมด ค้นหา กรองตามประเภท เรียงตามคอลัมน์ คลิกเพื่อกระโดดไปหา
- **วิเคราะห์** — centrality (degree / weighted / betweenness / closeness), ชุมชน (Louvain, label propagation), คอมโพเนนต์, เส้นทางสั้นสุด ผลแสดงเป็นขนาด/สี/ป้ายบนผัง + ตารางอันดับ
- **ตำนาน** — สีและจำนวนตามประเภท เลือก/ซ่อนทั้งประเภทได้

## เลย์เอาต์อัตโนมัติ

มายแมป (ซ้าย-ขวา รอบหัวข้อหลัก), ต้นไม้ บน→ล่าง / ซ้าย→ขวา (ตามทิศทางเส้น ตัดวงจรให้เอง), force-directed, วงกลม,
จัดกลุ่ม (ตามประเภท หรือตามชุมชนที่วิเคราะห์ได้), ไทม์ไลน์ (เรียงตามช่อง "วันเวลา" รองรับ `2025-02-10`, `10/02/2568`), ตาราง
ติ๊ก "จัดเฉพาะที่เลือก" เพื่อจัดเฉพาะโหนดที่เลือกอยู่ (ที่เหลืออยู่กับที่)

## นำเข้า / ส่งออก

- **JSON ของแอป** — เมนู ไฟล์ › บันทึก / เปิด (เก็บตำแหน่ง มุมมอง และสิ่งที่ซ่อนไว้ด้วย)
- **CSV** — เมนู ไฟล์ › นำเข้า CSV (เลือกไฟล์หรือวางข้อความ) รองรับ 3 แบบ ตรวจอัตโนมัติ:
  - *รายการโหนด*: คอลัมน์ `ชื่อ`/`label`, `ประเภท`/`type`, `วันที่`, `แหล่งที่มา`, `x`,`y` และคอลัมน์อื่น ๆ กลายเป็นแอตทริบิวต์
  - *รายการเส้น*: `from`, `to`, `label`, `weight`, `directed`, `date` …
  - *ตารางความสัมพันธ์แถวละ 1 แถว*: `ต้นทาง`, `ปลายทาง`, `ความสัมพันธ์` (+ `from_type`, `to_type`) — สร้างโหนดที่ยังไม่มีให้เอง
  - หัวตารางภาษาไทย/อังกฤษได้ ตัวแบ่ง `,` `;` `Tab` ได้ อ่านไฟล์ UTF-8 และ windows-874 ได้ ตัวอย่างอยู่ใน `assets/ตัวอย่าง/`
- **ส่งออกภาพ/เอกสาร** PNG (`Ctrl+E`) / JPEG / SVG / **PDF** (`Ctrl+P` หน้าพอดีผัง, หรือ A4/A3 แนวนอน — เขียน PDF เองไม่ใช้ไลบรารี) / CSV รายการโหนด / CSV รายการเส้น / Markdown outline

## สำหรับนักพัฒนา

- ไม่มีขั้นตอน build: `index.html` + `styles.css` + ES modules ใน `src/` (เปิดผ่านเซิร์ฟเวอร์เล็ก ๆ เพราะเบราว์เซอร์ไม่ให้โหลดโมดูลจาก `file://`)
- โครงสร้าง: `graph.js` โมเดล+undo, `layout.js` เลย์เอาต์ทั้งหมด, `analysis.js` อัลกอริทึมกราฟ, `csv.js` นำเข้า/ส่งออก, `render.js` SVG+การโต้ตอบ, `ui.js` แผงขวา, `export.js` PNG/SVG, `main.js` ประสานงาน/คีย์ลัด, `sample.js` ตัวอย่าง
- เทสต์: `npm test` (ใช้ `node --test` ไม่ต้องติดตั้งอะไร) ครอบคลุมโมเดล เลย์เอาต์ วิเคราะห์ และ CSV
