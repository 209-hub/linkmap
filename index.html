คีย์ลัดและวิธีใช้ LinkMap

ผืนผ้าใบ

  • ล้อเมาส์ ซูม · ลากปุ่มกลาง / Space+ลาก / เครื่องมือเลื่อน แพน
  • ปุ่ม + ข้างหัวข้อที่เลือก = เพิ่มหัวข้อย่อย (แตะได้บนแท็บเล็ต) · บีบสองนิ้ว ซูม/เลื่อน
  • ดับเบิลคลิกพื้นว่าง สร้างหัวข้อ · ดับเบิลคลิกหัวข้อ/เส้น แก้ข้อความ
  • ลากพื้นว่าง เลือกเป็นกรอบ · Shift+คลิก เลือกเพิ่ม/ลด
  • ลากจากจุดเล็กข้างโหนด (หรือ Alt+ลากโหนด) สร้างเส้นเชื่อม
  • คลิกขวา เมนูลัด · ลากมุมขวาล่าง ปรับขนาดโน้ต/กรอบ

คีย์ลัด

  • โหมดจดเรียน: Enter หัวข้อถัดไป (พี่น้อง) · Tab หัวข้อย่อย · พิมพ์ตัวอักษรบนหัวข้อที่เลือกเพื่อแก้ทันที · Ctrl+L จัดผังมายแมป
  • ✨ เอไอ: Ctrl+J สรุปเอกสารเป็นมายแมป — แอปคัดลอกคำสั่งให้ คุณวางใน Gemini/ChatGPT/Claude พร้อมแนบ PDF แล้วนำคำตอบ (JSON หรือโครงร่าง) มาวางกลับ ไม่ต้องใช้ API
  • ตกแต่ง: Ctrl+B ตัวหนา · Ctrl+I ตัวเอียง · Ctrl+V วางรูปลงหัวข้อ (หรือวางข้อความแบบรายการเพื่อสร้างกิ่ง) · ธีมสี/ธีมมืดที่เมนูมุมมอง · Ctrl+P ส่งออก PDF
  • มายแมป: ←↑↓→ เดินไปหัวข้อข้างเคียง · / ยุบ/ขยายกิ่ง · Ctrl+↑/↓ สลับลำดับ · Delete ลบทั้งกิ่ง · Shift+Del ลบเฉพาะหัวข้อ · Home ไปหัวข้อหลัก · ลากหัวข้อไปวางบนหัวข้ออื่น = ย้ายกิ่ง · Ctrl+M นำเข้าโครงร่างข้อความ
  • Space แตะ = สลับ เลือก ⇄ เลื่อน · กดค้างแล้วลาก = เลื่อนชั่วคราว
  • V เลือก H เลื่อน N โหนด L เส้น T โน้ต G กรอบ
  • Delete ลบ · Ctrl+Z/Ctrl+Y เลิกทำ/ทำซ้ำ · Ctrl+A เลือกทั้งหมด · Ctrl+D ทำสำเนา
  • 1–6 จัดผัง มายแมป / ผังองค์กร / force / วงกลม / กลุ่ม / ไทม์ไลน์ · เลือกโหนด ≥2 ก่อน = จัดเฉพาะที่เลือก · F ฟิต · 0 100%
  • E ขยายเพื่อนบ้าน · H(ขณะเลือก) ซ่อนที่ไม่เกี่ยว · Shift+H แสดงทั้งหมด · P เส้นทางสั้นสุด
  • Ctrl+S บันทึก JSON · Ctrl+O เปิด · Ctrl+F ค้นหา · \ ซ่อนแผงขวา · Esc ยกเลิก/ล้างการเลือก
